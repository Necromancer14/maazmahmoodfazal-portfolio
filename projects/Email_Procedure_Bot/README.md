# Email Procedure Bot

Oz, for a US insurance and healthcare client.

[Back to portfolio](../../README.md)

## Problem

Incoming emails had to be read, triaged and turned into tasks in the client system by hand.

## What I built

An agentic workflow that reads each incoming email, works out what it asks for, and creates a structured task in the client system.

## Result

- About **70%** less triage effort
- About **60%** fewer errors in task creation

## Stack

UiPath, LLM, agentic workflow, Azure DevOps releases
