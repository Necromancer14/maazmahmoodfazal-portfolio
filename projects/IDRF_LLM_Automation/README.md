# IDRF: donation data automation

HachiAi, for the International Development and Relief Foundation.

[Back to portfolio](../../README.md)

## Problem

The finance team spent hours downloading and reconciling donation data from Luminate Online, with inconsistencies and delays.

## What I built

1. The bot signs in to Luminate Online and extracts donation data.
2. An LLM maps and validates the fields.
3. The bot exports finance-ready files and a reconciliation report.

## Result

- Data accuracy up **42%**
- Manual work down **70%**

## Stack

UiPath, LLM, Luminate Online, Excel
